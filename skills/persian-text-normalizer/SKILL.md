# نرمال‌سازی متن فارسی

متن فارسی که از چت، وب، ورد یا کیبوردهای مختلف می‌آید معمولاً این مشکلات را دارد: «ي» و «ك» عربی، رقم‌های عربی، نیم‌فاصله‌ی جاافتاده، فاصله‌های اضافی، ویرگول انگلیسی. این مهارت آن‌ها را درست می‌کند **بدون اینکه محتوا یا لحن نویسنده را عوض کند**.

## روش کار

1. **متن کوتاه (چند خط):** همان‌جا اصلاح کن.
2. **فایل یا متن بلند:** از اسکریپت همین مهارت استفاده کن (فقط پایتون، بدون نصب چیزی):

   ```bash
   python3 scripts/normalize.py input.txt                  # نتیجه را چاپ می‌کند
   python3 scripts/normalize.py input.txt --in-place       # خود فایل را اصلاح می‌کند
   echo "كتاب ها ي من" | python3 scripts/normalize.py -    # از ورودی استاندارد
   python3 scripts/normalize.py input.md --digits fa       # همه‌ی ارقام ← فارسی
   ```

   پیش‌فرض (`--digits fix`) فقط رقم‌های عربی (٠١٢) را به فارسی (۰۱۲) برمی‌گرداند و ارقام لاتین را دست نمی‌زند. گزینه‌ها: `fa` همه فارسی، `en` همه لاتین، `keep` بدون تغییر.
3. نتیجه را بخوان و موارد «قضاوتی» (پایین) را خودت بررسی کن.
4. در پاسخ، **خلاصه‌ی تغییرات مهم** را بنویس (مثلاً «حروف عربی اصلاح شد، ۱۲ نیم‌فاصله اضافه شد»)، نه کل متن قبل/بعد.

## اسکریپت دقیقاً چه می‌کند

- ي، ى ← ی  و  ك ← ک
- ارقام عربی ← فارسی
- `,` `;` `?` بعد از حرف فارسی ← `،` `؛` `؟` (ویرگول بین دو رقم مثل ۳,۵ یا 1,000 دست‌نخورده می‌ماند)
- حذف کشیده (ـ)، فاصله‌های تکراری، فاصله قبل از `، ؛ ؟` و پایان جمله، فاصله داخل پرانتز
- نیم‌فاصله: «می خواهم ← می‌خواهم»، «نمی دانم ← نمی‌دانم»، «کتاب ها ← کتاب‌ها»، «کتاب های من ← کتاب‌های من»، «خانه ی من ← خانه‌ی من»
- **دست نمی‌زند به:** بلوک کد، `کد درون‌خطی`، نشانی‌های اینترنتی و ایمیل

## چیزهایی که اسکریپت عمداً رها می‌کند (با قضاوت خودت)

- **تر / ترین:** «بزرگ تر ← بزرگ‌تر» ولی «بهتر، بهترین» چسبیده است. چون «تر» (مرطوب) هم کلمه‌ی مستقل است، اسکریپت دست نمی‌زند.
- **پیشوندها و پسوندها:** «بی‌نظیر»، «نا‌امید»، «دانش‌آموز»، «همه‌گیر» و ... یکدست باشد.
- **«ه» + «ی»:** «خانه‌ی من» یا «خانهٔ من» هر دو رایج است؛ همان را که متن دارد در سراسر متن یکدست نگه دار.
- **اعراب:** اگر متن آیه، حدیث یا شعر مُعرَب است، `--strip-diacritics` نزن.
- **متن عربی:** اگر متن واقعاً عربی است (نه فارسی)، حروف ي/ك را عوض نکن؛ بپرس.

## قبل از تحویل

- متن نهایی همان معنا و همان ساختار پاراگراف‌ها را دارد؟
- کد، لینک و نام‌های لاتین دست نخورده‌اند؟
- ارقام در کل متن یکدست‌اند (همه فارسی یا همه لاتین، مگر کد، شناسه و شماره تلفن)؟
