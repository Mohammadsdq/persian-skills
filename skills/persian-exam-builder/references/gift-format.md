# فرمت GIFT برای Moodle (خلاصه)

GIFT یک فرمت متنی ساده برای وارد کردن سؤال به بانک سؤال Moodle است. فایل را با رمزگذاری **UTF-8** ذخیره کن تا فارسی درست نمایش داده شود.

## نمونه

```
::Q01::کدام میان‌بر متن انتخاب‌شده را کپی می‌کند؟{
~Ctrl+X
=Ctrl+C
~Ctrl+V
~Ctrl+Z
}

::Q02::در Excel فرمول با علامت \= شروع می‌شود.{TRUE}

::Q03::کلید میان‌بر ذخیره‌ی فایل در Word کدام است؟{
=Ctrl+S
}
```

## قواعد

- `::عنوان::` اختیاری است. بعد از آن متن سؤال و بلوک پاسخ در `{ }` می‌آید.
- `=` پاسخ درست، `~` پاسخ غلط، `#` توضیح یا بازخورد بعد از گزینه.
- صحیح/غلط: `{TRUE}` یا `{FALSE}`.
- کوتاه‌پاسخ: چند `=` پشت‌سرهم، هر کدام یک پاسخ پذیرفتنی.
- این نویسه‌ها داخل متن باید با `\` جلوشان بیایند: `~ = # { } :`. اسکریپت `exam_tools.py` خودش این کار را می‌کند.
- بین دو سؤال یک خط خالی بگذار.
- ورود: Moodle ← بانک سؤال ← وارد کردن ← قالب GIFT ← انتخاب فایل.

## قالب JSON ورودی اسکریپت

```json
[
  {"type": "mcq", "title": "Q01", "question": "کدام میان‌بر متن را کپی می‌کند؟",
   "options": ["Ctrl+X", "Ctrl+C", "Ctrl+V", "Ctrl+Z"], "answer": 1,
   "feedback": "Ctrl+C از کپی (Copy) می‌آید."},
  {"type": "tf", "question": "فرمول در Excel با = شروع می‌شود.", "answer": true},
  {"type": "short", "question": "میان‌بر ذخیره‌ی فایل در Word چیست؟", "answer": ["Ctrl+S"]}
]
```

برای سؤال چهارگزینه‌ای، `answer` اندیس صفرمبنای گزینه‌ی درست است (یا حرف `"A"` تا `"H"`).
